# Single-sentry Linux SIL, attempt8

This archive preserves the actual 30-second Linux single-sentry run, its exact driver/configuration and the separately qualified build/dispatch evidence. Earlier attempt7 remains a failed navigation run in its unchanged archive. No executable, dependency prefix, virtual environment, source clone or secret is bundled here.

The actual8 run completed 15,000 physics steps (30 simulated seconds), with measured RTF 0.9995295364. The original ROS recorder contains 294 requests, 292 localizations, 59 observed maps and 18 controller results. The original result records a 14-pose successful Smac path (status4) and an accepted FollowPath goal completing with status4. The controller raw log independently reports "Reached the goal!".

`independent_audit.py` reads the preserved original TRACE/ROS_SOURCE and independently checks every one of the **779 nonzero consumption steps**, across **18 distinct command identities**. Each joins the original enqueue and cloud frame/profile/acquisition window to the original ROS request, localization and controller result, with exact typed six-field identity, original location timestamp, body velocity, unchanged command, fire false, SDK ACK/lease/window and original 150 ms deadlines. Observed capture-wall ages range from 27.298349 to 148.928000 ms. The original harness consumption auditor was also rerun read-only and agreed; no ROS, physics or algorithm was rerun. The audit preserves 779 individual proof rows in `INDEPENDENT_AUDIT.json` and verifies the original input hashes remained unchanged.

The goal was a one-metre offset from the algorithm's estimated map-to-base pose. Its recorded coordinates and the 14 path poses/action statuses are supported by the frozen action-future result and its exact harness source, rather than a second independent raw action/TF reconstruction: ROS_SOURCE does not retain the original path action result or goal TF snapshot. The goal-completion controller log offers additional raw corroboration. Initial/final true qpos imply about 1.434 m physical displacement; this is a separately recorded post-run audit with `algorithm_input:false`, and was never navigation input.
