## Qualification metadata recommendations

The saved Gate payload predates the new schema/run fields: it has neither `schema` nor `run_uuid`. Its namespace matches the saved Session spec. Keep this historical payload unchanged. The current Worker already emits the new two fields, and the current driver checks them; these improvements belong to the next source revision.

For strict offline qualification, validate Gate as an exact known field set: schema `polar.pb.production-gate-status.v1`; exact-string 32 lowercase-hex run UUID equal to the prepared Session; namespace exactly `/polar_sil_<run>/red_sentry`; production and activation flags exact bool; stack state exact string `ACTIVE`; map/odometry counts exact integers excluding bool, nonnegative and positive for success; latest odometry stamp exact nonnegative integer; errors exact list of strings, empty for success; clock domain exactly `linux_local_receive_only`. Missing errors is not equivalent to an empty errors list. Metadata clocks remain diagnostic only.

Validate peer result against `polar.pb.external-goal-result.v1`, the independent peer's exact run UUID, its prepared parent Session UUID and derived namespace, and the saved peer spec/environment/source hashes. This attempt's peer schema/run/Session run/namespace all match. Require exact bool values for goal completion, lifecycle_changed, sensor_published and cmd_vel_published, rather than truthy strings. Require finite nonnegative elapsed time and typed goal/result status data; a filename alone does not bind a report to a run. Resource cleanup is separately tied to the original supervisor/child PID, start ticks, boot ID and run/spec identity, and a false or absent cleanup cannot qualify. The failed peer was reaped with an empty owned group, but its operation-error cleanup is deliberately false; do not reinterpret it as a leak or successful goal.

The current driver now matches Gate/peer schema, namespace and run identities and rejects bool counts. Further typed report validation is useful against incomplete or corrupted artifacts. This recommendation does not assert a new Host protocol defect: actual Session replies and authority deadlines already use strict validation and the prepared fresh directories/source pins supply the live boundary.

Reproduce the saved analysis with `.venv-sim/Scripts/python.exe artifacts/pb-wsl-production-phase-audit-20261014-01/audit.py` in a fresh equivalent output directory. This exact directory is frozen after its first successful run; the script intentionally refuses to overwrite `raw`.
