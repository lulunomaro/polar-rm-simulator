# RCLCPP dispatch fixtures and controller diagnostic build

These are real subprocess/build/DDS measurements on **synthetic fixtures**, plus a diagnostic controller shared-library build/load. They do not establish Point-LIO timing, successful navigation, a SIL run, or hardware behavior. The separately frozen actual7 archive retains its zero-actuation/navigation failure.

| `dds/COMMAND.json`, `dds/configure.json`, `dds/compile.json` | The second fresh synthetic fixture actually configured and compiled with its recorded environment; no earlier result was overwritten. |
| `dds/RESULT.json`, `dds/some.json`, `dds/all.json` | Two real DDS processes delivered the same 51 original synthetic IMU timestamps. These are Linux-local steady-clock diagnostic timings. No LIO, simulator, NN, GL or future-IMU fabrication was exercised. |

`MANIFEST.json` records original artifact/source path, byte length and SHA256, plus stored path, byte length and SHA256. Large text uses gzip with mtime0 and no embedded source filename. Every decompressed stored file is compared byte-for-byte with the source and the source is reread to check it stayed unchanged. No executable binaries, dependency prefix or virtual environment are included. Earlier evidence files and archives remain unchanged.
