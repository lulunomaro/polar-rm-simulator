## Minimal next causal evidence

First add bounded per-transaction supervisor metadata: stdout readable observation count, cumulative actually read stdout bytes, retained partial-buffer length and bounded-prefix SHA, first-readable/first-read offsets after native stdin completion, plus exception-time local deadline/select observations. Record only scalars/bounded hashes; do not consume or accept a result after the original deadline, perform hot-path disk logging, add inference warmups or extend 80/150 ms. This can distinguish an observed partial response from no supervisor-observed bytes, while zero read bytes still cannot prove no child write.

If the child compute phase remains unknown, use an explicitly distinct, source-pinned diagnostic profile on this exact preserved frame/calibration/exposure/control identity. Existing first-frame tracing must cover native input/BGR read, request allocation/resize, infer begin/end, postprocessing and serialization, and a separate begin/end around main's actual stdout write/flush. All timestamps must be Linux-local and phases associated with the same real frame; missing END at kill stays incomplete. Such a diagnostic ELF is not the unchanged production ELF, and its profile overhead cannot be used to manufacture live qualification. An optional same-owned-process `/proc` scheduling/syscall observation at stdin completion and rejection can add scheduling evidence without editing the original native algorithm, but does not itself isolate NN time.
