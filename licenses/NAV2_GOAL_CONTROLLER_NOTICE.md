# Nav2 goal-associated controller overlay notice

The owned controller executable generated by
`tools/prepare_nav2_goal_controller_overlay.py` derives from the official
[Navigation2 repository](https://github.com/ros-navigation/navigation2), release
**1.1.20**, fixed Git revision
**a097086719c88f781aa59788eca29ac6ca5e56db**.

The upstream controller inputs are `nav2_controller/src/controller_server.cpp`,
`nav2_controller/src/main.cpp`,
`nav2_controller/include/nav2_controller/controller_server.hpp`,
`nav2_controller/CMakeLists.txt`, and `nav2_controller/package.xml`. The generator
checks their exact SHA256 values before creating a fresh owned source directory.
The original source copyright and license notices are retained in the generated
source files. Upstream CMake and package metadata are also retained as
`UPSTREAM_CMakeLists.txt` and `UPSTREAM_PACKAGE.xml`.

The owned ActionServer wrapper is copied from the installed Nav2 1.1.20 header:

```text
/root/polar-humble-ext4-20261014-01/prefix/opt/ros/humble/include/nav2_util/simple_action_server.hpp
SHA256: 942c09496c49f8343e360a549819582b299ddae7b07fc3e2678a57568d2df8cc
```

Its upstream source is
[`nav2_util/include/nav2_util/simple_action_server.hpp`](https://github.com/ros-navigation/navigation2/blob/a097086719c88f781aa59788eca29ac6ca5e56db/nav2_util/include/nav2_util/simple_action_server.hpp).
The installed header is an immutable input: the generator verifies this digest,
copies the header into the new owned source directory, preserves its original
notice, and adds the current-goal capture and publication guards there.

These Nav2 sources carry the Intel Corporation copyright notice and are licensed
under the Apache License, Version 2.0. The complete license is provided in
[`Apache-2.0.txt`](Apache-2.0.txt), copied byte for byte with its original LF line
endings from `/usr/share/common-licenses/Apache-2.0`:

```text
SHA256: cfc7749b96f63bd31c3c42b5c471bf756814053e847c10f3eb003417bc523d30
```

The local changes use the independent `polar_nav2_controller` and
`polar_nav2_util` namespaces and a standalone executable. They associate one
successful controller computation with the actual accepted FollowPath handle,
its captured UUID, and the original scan/localization context. Cancellation,
preemption, lifecycle, and source checks guard publication. The executable loads
the existing PB PID controller plugin through the original plugin interface;
the overlay does not supply a replacement navigation or control algorithm.

Each generated `SOURCE_IDENTITY.json` records the fixed upstream revision,
original and generated file hashes, installed header hash, generator hash, and
local context-header hash. The separate `BUILD_RESULT.json` identifies the new
executable and its compilation/loader evidence. These records distinguish the
owned overlay from the unchanged installed Nav2 executable and PB plugin.
