# Public source scope

Included: 190 byte-identical source files from the pinned subtree, one exact-function reference excerpt, runtime and generic tests, analytic MJCF/arena metadata and preview, generic season configuration, requirements, build/launch entry scripts, protocol documentation, and applicable attribution. New repository packaging files are separate from the original source identity.

Excluded: 191 other original files, including historical logs and run summaries, internal review/checkpoint reports and manifests, obsolete broad-copy publication helpers, private execution evidence, unrelated HTTP/LLM/ROS reference material, and historical fixture servers requiring omitted freeze inputs. The original source repository retains historical provenance.

No credentials, machine-local runtime specs, private hardware identifiers, personal logs, native binary, policy weight, official CAD mesh, private scene initial state, or private storage reference is included. Analytic XML scenes and public-rule-derived geometry are source assets, not trained model weights.

The owner authorized public MIT release of owned simulator code and permits models to be published. A later, separately reviewed supplement includes the exact historical detector weight `models/shenzhen-0526.onnx`, its pinned provenance, original upstream MIT notice, and unchanged interface references. The upstream root license does not explicitly discuss weights; no model-specific restriction was found, and training-data provenance and original weight authorship were not independently established. See `models/README.md`. Availability and redistribution rights must be checked for every other model addition. The permission does not make absent or third-party-restricted assets available.

Manual SIM v2, stationary fire-off 24-exposure OFFLINE SIL, and the separately frozen timing-v5 full-match entry remain distinct. This publication performs only syntax, byte-integrity and selected synthetic contract checks. It does not install dependencies, run physics/rendering/native inference, start a paid API, launch a CI workflow, or establish Windows/LAN/hardware qualification.

The small arena verification.json is retained as geometry provenance from the source snapshot; its historical ray/render checks were not rerun during extraction.
